# Audionyx

---

>WaveSmith is an open‑source, browser‑based sound editor built for creators who want power without complexity. Load audio instantly, edit it directly in your browser, visualize waveforms in real time, and export clean, high‑quality results — all without installing anything.
> 
>Designed to be lightweight, fast, and accessible, WaveSmith uses the Web Audio API and a modular effect system to deliver professional‑grade tools in a simple interface. Whether you’re trimming clips, adjusting levels, applying fades, or building full effect chains, WaveSmith keeps everything intuitive and transparent.
> 
>A desktop version powered by Electron will be available later for users who prefer a native app experience, while the core codebase remains fully open‑source and community‑driven.
